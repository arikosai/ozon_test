# Hero Finder

Функция, которая принимает на вход пол и наличие работы (булево значение) и возвращает по этим критериям самого высокого героя, используя API https://akabab.github.io/superhero-api/api/all.json

## Установка

1. Клонировать репозиторий
2. Установить внешние пакеты:

pip install -r requirements.txt

## Запуск программы

python main.py

Скрипт запросит пол героя (Male или Female) и наличие работы (True или False) и выведет имя и рост самого высокого героя, подходящего под эти критерии.

## Запуск тестов

Все тесты находятся в test_hero_find_func.py и написаны на pytest.

Запустить все тесты:

pytest

Более подробный вывод:

pytest -v

### Что тестируется

- выбор самого высокого героя с учётом фильтра по полу и наличию работы;
- корректная работа при отсутствии подходящих героев;
- обработка неполных данных — отсутствие роста, отсутствие полей 'appearance'/'work';
- отдельно тест функции парсинга роста в см на разных форматах входных данных.
